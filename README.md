# SDN-Enabled QoS-Aware GPON Architecture for Smart City Networks

This project proposes an SDN-enabled QoS-aware GPON architecture designed to improve network performance in smart city communication systems. The system integrates Software-Defined Networking (SDN) with GPON to achieve dynamic bandwidth allocation, efficient traffic management, and enhanced Quality of Service (QoS).

## Features

* SDN-enabled GPON architecture design
* Dynamic bandwidth allocation using centralized SDN control
* Traffic classification based on QoS priority levels
* QoS-aware scheduling at the Optical Line Terminal (OLT)
* Performance evaluation under varying network traffic conditions

## Technologies Used

* MATLAB
* GPON
* Software-Defined Networking (SDN)
* QoS Scheduling

## Performance Metrics

* Throughput
* Latency
* Jitter
* Packet Delivery Ratio (PDR)
* Bandwidth Utilization

## Applications

* Smart City Communication Networks
* IoT Infrastructure
* Intelligent Transportation Systems
* Next-Generation Optical Access Networks
